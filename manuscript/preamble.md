# LaTeX Preamble

LaTeX packages and commands injected into the PDF compilation. Parsed by
`infrastructure/rendering/latex_utils.py` and combined by the PDF renderer before
the final Pandoc/XeLaTeX pass.

```latex
% Core mathematics
\usepackage{amsmath}
\usepackage{amssymb}
\usepackage{amsfonts}

% Document layout
% Deliberately compact research layout: the rendered PDF is checked for overflow
% after every artifact regeneration (the same value is mirrored in config.yaml).
\makeatletter
\@ifpackageloaded{geometry}
  {\geometry{top=0.42in,bottom=0.45in,left=0.38in,right=0.38in,includeheadfoot}}
  {\usepackage[top=0.42in,bottom=0.45in,left=0.38in,right=0.38in,includeheadfoot]{geometry}}
\makeatother
\usepackage{float}
\usepackage{graphicx}

% Tables
\usepackage{booktabs}
\usepackage{longtable}
\usepackage{array}

% Code listings (DSPy-style signatures appear as code blocks)
\usepackage{listings}
\newtheorem{theorem}{Theorem}[section]
\newtheorem{remark}[theorem]{Remark}
\newtheorem{example}[theorem]{Example}

% Typography and formatting
\usepackage{microtype}
\usepackage{xcolor}

% Cross-references and citations
\makeatletter
\@ifpackageloaded{hyperref}
  {\hypersetup{colorlinks=true,linkcolor=red,urlcolor=red,citecolor=red,anchorcolor=red,filecolor=red}}
  {\usepackage{hyperref}\hypersetup{colorlinks=true,linkcolor=red,urlcolor=red,citecolor=red,anchorcolor=red,filecolor=red}}
\makeatother
\usepackage[capitalise,noabbrev]{cleveref}
\usepackage{natbib}
\usepackage{etoolbox}
% Cover visual abstract generated by src/figures/diagrams.py. The relative path
% is resolved from output/pdf/, where the combined manuscript is compiled. The
% explicit text-width wrapper avoids inheriting the narrower author layout.
\newcommand{\thaliacover}{%
  \par\noindent
  \parbox{\textwidth}{%
    \centering
    \makebox[\textwidth][c]{%
      \includegraphics[width=0.99\textwidth,height=0.42\textheight,keepaspectratio]{../figures/thalia_cover.png}%
    }\par
    \vspace{0.45em}%
  }%
  \par\nobreak
}
% The template generates the title/subtitle and author/DOI/date macros before
% this project preamble is injected.  Prepending the cover to the generated
% author macro places it after the title/subtitle and before the author block,
% while keeping the DOI status config-driven. The parbox/makebox also preserves
% the intended title -> cover -> author/date order without overflow-prone hacks.
\makeatletter
\let\thaliaoriginalauthor\@author
\renewcommand{\@author}{\thaliacover\thaliaoriginalauthor}
\makeatother
```
