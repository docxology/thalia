# LaTeX Preamble

LaTeX packages and commands injected into the PDF compilation. Parsed by
`infrastructure/rendering/latex_utils.py` and combined by the PDF renderer before
the final Pandoc/XeLaTeX pass.

```latex
% Core mathematics
\usepackage{amsmath}
\usepackage{amssymb}
\usepackage{amsfonts}

% Document layout
% Deliberately compact research layout: the rendered PDF is checked for overflow
% after every artifact regeneration (the same value is mirrored in config.yaml).
\makeatletter
\@ifpackageloaded{geometry}
  {\geometry{top=0.42in,bottom=0.45in,left=0.38in,right=0.38in,includeheadfoot}}
  {\usepackage[top=0.42in,bottom=0.45in,left=0.38in,right=0.38in,includeheadfoot]{geometry}}
\makeatother
\usepackage{float}
\usepackage{graphicx}

% Tables
\usepackage{booktabs}
\usepackage{longtable}
\usepackage{array}

% Code listings (DSPy-style signatures appear as code blocks)
\usepackage{listings}

% Typography and formatting
\usepackage{microtype}
\usepackage{xcolor}

% Cross-references and citations
\makeatletter
\@ifpackageloaded{hyperref}
  {\hypersetup{colorlinks=true,linkcolor=red,urlcolor=red,citecolor=red,anchorcolor=red,filecolor=red}}
  {\usepackage{hyperref}\hypersetup{colorlinks=true,linkcolor=red,urlcolor=red,citecolor=red,anchorcolor=red,filecolor=red}}
\makeatother
\usepackage[capitalise,noabbrev]{cleveref}
\usepackage{natbib}
\usepackage{etoolbox}
% Cover visual abstract generated by src/figures/diagrams.py. The relative path
% is resolved from output/pdf/, where the combined manuscript is compiled.
\newcommand{\thaliacover}{%
  \includegraphics[width=0.92\textwidth,height=0.28\textheight,keepaspectratio]{../figures/thalia_cover.png}\par
  \vspace{0.55em}%
}
\apptocmd{\titlepage}{\thaliacover}{}{}
```
