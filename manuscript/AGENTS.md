# `manuscript/` — Agent contract

## Token substitution protocol

- Every numeric *result* in prose is a `{{TOKEN}}` placeholder, never a hand-typed
  value. The full token set is emitted by
  `src/manuscript_variables.py::generate_variables`.
- After editing prose that adds a numeric claim, add the corresponding token to
  `generate_variables`, then run
  `scripts/z_generate_manuscript_variables.py` — it fails if any `{{TOKEN}}` used
  in the manuscript is not emitted by the generator.
- Do **not** write a literal `{{TOKEN}}` as a meta-reference; use `{{…}}` (ellipsis)
  so the coverage check does not treat it as a real token.

## Editing rules

- Section files are numbered `00_`–`99_`; lettered split files such as
  `04a_*.md` and `07a_*.md` are rendered in lexical order. Keep the
  `{#sec:...}` anchors stable (cross-references use `[@sec:...]`).
- Citations use Pandoc `[@key]` resolved from `references.bib`. Entries marked
  "as provided" are transcribed from the commissioning brief — do not assert
  independent verification.
- **Preserve the two scope boundaries** in [`07_evaluation.md`](07_evaluation.md):
  the extractive-LM accuracy ceiling and the hashing-embedding semantic surrogate.
  Generated or edited text must not claim the lexical-vs-dense magnitude is
  reproduced locally.
- Figures live in `output/figures/` (regenerated by `scripts/generate_figures.py`)
  and are referenced with `{#fig:...}` labels.
